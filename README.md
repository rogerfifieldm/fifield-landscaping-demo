# Verdant Estate Landscapes — Portfolio V4
Fictional landscaping website by Fifield Digital. This version uses **local assets** cropped from the approved concept mockup, rather than unrelated external stock-photo URLs. These are **illustrative images**, not actual landscaping work or before-and-after project records. Replace with full-resolution licensed/client photography for production. The demo inquiry form does not send or store data.

Upload `index.html`, `styles.css`, `script.js`, and the entire `assets` folder to the root of `fifield-landscaping-demo` on GitHub. Keep filenames and paths unchanged. The `README.md` is optional. The only external dependency is a Google Fonts stylesheet; fallback system fonts are provided.
