# Verdant Estate Landscapes — Portfolio V6

Fictional landscaping website demonstration designed and developed by Roger Fifield.

## Upload to GitHub Pages
Upload `index.html`, `styles.css`, `script.js`, and the complete `assets/` folder to the root of `rogerfifieldm/fifield-landscaping-demo`. Keep folder names intact.

## Photography
The site includes three real commercial installation photographs from Roger Fifield’s former landscaping business. Verdant is fictional and did not complete that project. The four free Unsplash stock photos are referenced by their image-host URLs; their originals **could not be downloaded into this package**. Local illustrative fallback images are included so the layout remains usable if the remote images do not load. These local fallback images are illustrations, not photos of completed work.
