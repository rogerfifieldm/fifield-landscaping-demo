# Verdant Estate Landscapes
Premium landscaping portfolio concept by Fifield Digital.

## Preview
Open `index.html` in a browser, or deploy the folder to GitHub Pages.

## Important
This is a fictional portfolio demonstration, not a real business. The form does not send or store inquiries. Photos are externally hosted illustrative Unsplash images and require internet access; replace with properly licensed landscaping photography for a client launch.

## Customize
Edit brand, service categories, copy, and photos in `index.html` and `styles.css`. Mobile menu and demo form behavior are in `script.js`.
